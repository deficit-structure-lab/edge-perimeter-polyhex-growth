SETTING

Index the cells of the hexagonal lattice by integer pairs (q, r). Two cells
are adjacent if their difference is one of

  (1,0), (0,1), (-1,1), (-1,0), (0,-1), (1,-1).

A polyhex is a finite, nonempty set of cells that is connected under
adjacency. For a polyhex S, let a(S) be the number of unordered adjacent
pairs of cells both lying in S, and define the edge perimeter

  p(S) = 6|S| - 2a(S)

[six times the number of cells, minus twice the number of adjacent pairs].

This equals the number of lattice edges separating S from its complement.

GIVEN FACT (may be used without proof)

For every N >= 1, the minimum of p over all N-cell polyhexes is

  p_min(N) = 2 g(N),  where g(N) = ceil( sqrt(12N - 3) )

[g(N) is the smallest integer that is at least the square root of
12N - 3; p_min(N) is twice that].

An N-cell polyhex S with p(S) = p_min(N) is a minimizer. The excess is

  exc(S) = p(S) - p_min(|S|)

[the actual edge perimeter minus the minimum possible for that number of
cells]; exc(S) is a nonnegative even integer.

TASK A (main)

Prove: for every N >= 1 and every N-cell minimizer S, there exist
polyhexes

  S_1 ⊂ S_2 ⊂ ... ⊂ S_N = S

with |S_k| = k such that

  (a) for each 1 <= k < N,
      S_{k+1} = S_k ∪ {c}
      for some cell c adjacent to at least one cell of S_k,

and

  (b) exc(S_k) <= 2
      for every 1 <= k <= N.

TASK B

Prove that the constant 2 in (b) cannot in general be replaced by 0.
